# CS2 遊戲滑鼠延遲（卡頓）排查

## 影片中的觀察與結果

在影片使用的 Wayland／KDE 環境中，CS2 全螢幕模式下滑鼠操作感覺明顯延遲、卡頓；切換成視窗模式後，操作流暢度改善。再切回全螢幕時，延遲再次出現。

影片中也測試了 KWin 的「允許畫面撕裂」設為「強制」，但開啟全螢幕並沒有改善這個問題。最後實際有效的調整是把 CS2 顯示模式改為視窗模式。移除標題列或視窗框不是必要步驟。

## 建議測試方式

1. 記下目前遊戲顯示模式與 KWin 畫面撕裂設定。
2. 在相同場景中測試全螢幕模式，觀察滑鼠移動是否有延遲或卡頓。
3. 只把遊戲顯示模式改為視窗模式，再在相同場景比較。
4. 如需確認畫面撕裂設定的影響，另一次測試只改該設定，避免同時改多項而無法判斷原因。

各遊戲、顯示器、顯示卡、驅動與桌面設定可能不同；這是個人測試結果，不保證視窗模式對所有人都會改善，也不代表已確定底層根因。

## 還原

在遊戲顯示設定中將顯示模式改回原本選項；若有更改 KWin 畫面撕裂設定，也將其恢復為原值。
